# DeBERTa baseline

This directory preserves jev-my-bro v0.1: a three-class DeBERTa sequence classifier with temperature scaling, ONNX export, and local inference.

It is no longer the active architecture. Keep it for comparative experiments against the Laya-based v0.2 pipeline at the repository root.

The baseline data is also preserved here. Do not mix its validation/calibration/test splits into the active Laya training split.
